
# The Butterfly Effect: Case 001

An interactive mystery storytelling game where players investigate a disappearance through branching choices, uncover hidden evidence, build relationships with characters, and experience multiple endings based on their decisions. Built using HTML, CSS, JavaScript and Python.

## About the Project

**The Butterfly Effect: Case 001** is a choice-driven mystery game set in Bengaluru, India. Players take on the role of an investigator tasked with uncovering the truth behind a mysterious disappearance.

Every decision influences how the investigation unfolds. Conversations, clues, character relationships and important choices can change the direction of the story and determine its final outcome.

## Storyline

A journalist has mysteriously disappeared, leaving behind a series of unexplained events and unanswered questions.

As the investigation begins, players encounter several characters, each with their own motives, secrets and connections to the case.

Players must investigate locations, question suspects, collect evidence and make decisions that gradually reveal the truth.

## Game Features

- **Branching Storyline:** Decisions influence the direction of the story.
- **10 Chapters:** Explore a connected mystery across ten chapters.
- **Multiple Choices:** Four choices are available in every chapter.
- **Character Interactions:** Build relationships and uncover character secrets.
- **Evidence Collection:** Discover clues throughout the investigation.
- **Dynamic Statistics:** Track evidence, trust and reputation.
- **Multiple Endings:** Experience different conclusions based on your decisions.
- **Replayability:** Replay the game and explore alternative story paths.
- **Humorous Choices:** Discover unexpected outcomes through special goofy decisions.

## Getting Started

### Prerequisites

- A modern web browser such as Google Chrome or Microsoft Edge.
- Python installed if using the Python components.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/jaishcodes/The-Butterfly-effect-Case-001.git
   ```

2. Navigate to the project directory:

   ```bash
   cd The-Butterfly-effect-Case-001
   ```

3. Open `index.html` in your browser to start playing.

If you are using the Python backend, follow the setup instructions provided in the project files.

## How to Play

1. Launch the game.
2. Begin the investigation.
3. Read the story and interact with characters.
4. Choose from the available options.
5. Collect evidence and monitor your investigation statistics.
6. Complete all ten chapters.
7. Discover your ending based on the decisions you made.
